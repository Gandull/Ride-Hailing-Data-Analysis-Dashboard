# Ride-Hailing Fleet Data Analysis (Excel)

This data analytics project evaluates fleet efficiency and driver performance for a ride-hailing dataset. The analysis processes historical trip data, tracking exact dispatch times and ride durations.

## Core Features Implemented:
* **Time-Series Processing**: Structured raw timestamp data to isolate operational shifts.
* **Advanced Metrics**: Utilized Excel formulas to compute precise ride durations and driver efficiency.
* **Data Aggregation**: Built dynamic Pivot Tables to segment performance across peak vs. off-peak windows.
* **Visual Reports**: Generated operational charts outlining efficiency trends.

## File Included:
* `project.xlsx` - Contains the full data pipeline, formulas, pivot tables, and dashboard.
